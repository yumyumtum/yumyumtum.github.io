抵达日 · 住 PORT ANGELES

Sammamish → Edmonds → Kingston → Port Angeles

从 Sammamish 开到 Edmonds 码头。车开上渡轮，过海约 30 分钟；到 Kingston 后继续开往 Port Angeles。到酒店后只安排吃饭和休息。

预留 4–5 小时（含渡轮排队和乘船）

FERRY HOW-TO

带车坐渡轮，怎么走？

  1. 开车到 Edmonds 码头，夏天平日建议比船班早 45–60 分钟到。
  2. 在车辆队伍里等候；可以短暂下车活动，但不要走远。
  3. 按工作人员指挥把车开上船，熄火锁车后去客舱或甲板。
  4. 靠岸前回到车里，抵达 Kingston 后直接开下船。

HIGHLIGHTS

这趟能看到什么？

Hurricane Ridge

坐车直达高山观景点；游客中心和洗手间对行动不便的长辈更友好。

Lake Crescent

湖边停留、午餐和看景即可，不必安排较长的瀑布步道。

Ruby + Kalaloch

Ruby 看海蚀柱和潮池；Kalaloch 是宽沙滩，适合坐着看海和日落。

给长辈的小提醒

优先选择观景台、游客中心、湖边和沙滩上容易停留的区域。Ruby Beach 下到海边的路较陡，可只在观景台拍照；Hurricane Ridge 出发前查看当天路况，并携带饮用水。
