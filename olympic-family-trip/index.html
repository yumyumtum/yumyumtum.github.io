轻松的家庭旅行

从 Sammamish 出发的三天小旅行：坐渡轮、看湖、看太平洋海滩和山景。节奏适合长辈、小学生和高中生。

坐船要点

带车上渡轮

  1. 夏天开车去 Edmonds 码头要早到，排队可能较久。
  2. 按工作人员指挥把车开上船，熄火锁车。
  3. 大家可以去客舱、甲板和洗手间，不必坐在车里。
  4. 靠近 Kingston 时回车上，准备下船。

三个轻松亮点

全家真正能享受的地方

Crescent 湖

看湖、上洗手间、看看小屋；不用安排走瀑布步道。

Ruby + Kalaloch

Ruby 看海蚀柱；想舒服坐海边，就选沙滩更宽的 Kalaloch。

Hurricane Ridge

晴天时开车到观景点即可看山，不需要爬山。

给长辈的舒适安排

订房时确认无障碍或一楼房、步入式淋浴、停车、电梯和早餐距离。Ruby Beach 下到海边的路很陡，累了就在观景点拍照即可。Hurricane Ridge 山景取决于天气，随时可以跳过。

预订与出发清单

出发前要知道的事

酒店需要预订；渡轮和国家公园不用选时间预约。

渡轮：不能预约车位

Edmonds ↔ Kingston 车辆按到达顺序上船。夏季平日提前 45–60 分钟到；周五和周末最好更早。排队时在车里等，带水和零食，别离车太远。

上船后：熄火锁车，大家可去客舱、甲板和洗手间；靠岸前回车上。

渡轮：费用与回程

以一辆普通车、两位成人、两位长辈、两位未成年孩子估算，往返约 $88；18 岁及以下免费。去程在 Edmonds 付乘客和车辆费；回程 Kingston 付车辆费。价格可能调整，以官网当天为准。

公园与酒店

奥林匹克国家公园不需要 timed-entry。私家车 $30，连续 7 天、全车人都包含；如长辈有 Senior Pass，可直接使用。Port Angeles 酒店住两晚最省心，应尽早订无障碍或一楼房。
